01 — About

Curious by default,
building by habit.

Hello — I’m Arjun, an MCA student with a BCA from Yenepoya Deemed to be University, Bangalore. I’m drawn to the part of programming where a blank file turns into an application someone can use: a storefront, a social feed, a shoe you can spin around.

I work mostly in Python and the web — Django on the server, HTML, CSS and JavaScript in the browser, SQL underneath. Lately I’ve been pushing into React and Three.js because interactive 3D feels like the next honest step for e-commerce.
